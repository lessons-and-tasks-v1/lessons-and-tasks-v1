## Задача №1 «Имя для летописи»

— Прежде чем отправиться в путь, назовись, — сказал Элронд. — Летопись должна знать, кого она увековечит.

Напиши программу, которая:
1. Считывает имя героя и сохраняет его в переменную `name`.
2. Считывает название родного края и сохраняет его в переменную `home`.
3. Выводит фразу: `Герой <имя> из <край>`.

**Формат ввода**
1. Имя.
2. Край.

**Формат вывода**
Одна строка с приветствием.

| Ввод | Вывод |
| :--- | :--- |
| Арагорн | Герой Арагорн из Гондор |
| Гондор | |

## Задача №2 «Возраст в днях»

— Сколько тебе лет, хоббит? — спросил Гэндальф.
— Пятьдесят, — ответил Бильбо.
— А сколько это дней? Это важно для карты.

Напиши программу, которая:
1. Считывает целое число — возраст в годах — и сохраняет в переменную `age`.
2. Создаёт переменную `days` и присваивает ей значение `age * 365`.
3. Выводит значение переменной `days`.

**Формат ввода**
Одно целое число.

**Формат вывода**
Одно целое число — количество дней.

| Ввод | Вывод |
| :--- | :--- |
| 50 | 18250 |
| 1 | 365 |

## Задача №3 «Цена похода»

— Каждый воин получает 3 золотых в день, — сказал казначей. — Посчитай, во что обойдётся поход.

Напиши программу, которая:
1. Считывает количество воинов — переменная `warriors`.
2. Считывает количество дней похода — переменная `days`.
3. Создаёт переменную `total` и присваивает ей `warriors * 3 * days`.
4. Выводит значение переменной `total`.

**Формат ввода**
1. Число воинов.
2. Число дней.

**Формат вывода**
Одно целое число — общая стоимость.

| Ввод | Вывод |
| :--- | :--- |
| 9 | 270 |
| 10 | |

## Задача №4 «Тип данных артефакта»

— Каждый артефакт имеет свою природу, — сказал Гэндальф. — И важно понимать, с чем именно ты имеешь дело.

Напиши программу, которая:
1. Считывает строку — название артефакта, сохраняет в переменную `name`.
2. Считывает целое число — его возраст, сохраняет в переменную `age`.
3. Выводит тип данных переменной `name` и тип данных переменной `age`.

**Формат ввода**
1. Название.
2. Возраст (целое число).

**Формат вывода**
Две строки: тип первой переменной, затем тип второй.

| Ввод | Вывод |
| :--- | :--- |
| Кольцо | <class 'str'> |
| 3000 | <class 'int'> |

## Задача №5 «Проверка пароля Ворот»

— Скажи, друг, и войди, — прочитал Гэндальф древние письмена на камне. — Здесь нужен пароль. Но не простой, а произнесённый с правильной интонацией.

Напиши программу, которая проверяет пароль. Считывается одна строка — попытка пароля, сохраняется в переменную `password`. Пароль считается верным, если одновременно выполняются три условия:
1. Длина строки **ровно 8 символов**.
2. Строка начинается с буквы **"М"** (заглавной).
3. Строка заканчивается на **"!"**.

Если пароль верный — вывести **"ВОРОТА ОТКРЫТЫ"**, иначе — **"НЕВЕРНЫЙ ПАРОЛЬ"**.

**Формат ввода**
Одна строка.

**Формат вывода**
Одна строка с результатом.

| Ввод | Вывод |
| :--- | :--- |
| Мория!х | НЕВЕРНЫЙ ПАРОЛЬ |
| Мория123! | ВОРОТА ОТКРЫТЫ |

## Задача №6 «Булевы знамёна»

— Подними знамя, если мы готовы к бою, — сказал Арагорн. — И опусти, если нет.

Напиши программу, которая:
1. Считывает слово — `"да"` или `"нет"` — и сохраняет в переменную `answer`.
2. Создаёт переменную `ready` типа `bool`: `True`, если `answer == "да"`, иначе `False`.
3. Выводит значение переменной `ready`.

**Формат ввода**
Одна строка — `да` или `нет`.

**Формат вывода**
Одно значение типа `bool`.

| Ввод | Вывод |
| :--- | :--- |
| да | True |
| нет | False |

## Задача №7 «Пустое место в свитке»

— Иногда в свитке нет записи, — сказал Бильбо. — И это тоже важно. Это не ноль и не пустая строка. Это — ничего.

Напиши программу, которая:
1. Создаёт переменную `record` и присваивает ей значение `None`.
2. Выводит значение переменной `record`.
3. Выводит тип переменной `record`.

**Формат ввода**
Нет ввода.

**Формат вывода**
Две строки: значение `None` и его тип.

| Ввод | Вывод |
| :--- | :--- |
| | None |
| | <class 'NoneType'> |
