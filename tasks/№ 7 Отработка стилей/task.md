## Задача №1 «Семейное древо стилей» (Наследование и `inherit`)

— В CSS одни свойства передаются «по наследству», а другие — нет. Это нужно чётко понимать.

Создай HTML-страницу со следующей структурой:

```html
<div class="parent">
    Текст родителя
    <p>Абзац внутри родителя</p>
    <span>Строчный элемент</span>
</div>
```

Напиши такие стили, чтобы:

1. У `.parent` был задан цвет текста (например, синий), размер шрифта (`20px`) и рамка (`border`).
2. У тега `<p>` внутри родителя цвет текста стал **красным**, но размер шрифта остался **таким же, как у родителя** (не указывай размер явно, пусть наследуется).
3. У `<span>` внутри родителя **не было** рамки, хотя у родителя она есть.
4. У `<span>` цвет текста принудительно сделай **зелёным**, используя ключевое слово для принудительного наследования от родителя? *(Нет, это ошибка — зелёный не наследуется от синего. Сделай зелёным напрямую).*

**Вопрос для размышления (ответь комментарием в коде):**
Почему `border` не «перешёл» от родителя к `<span>`, а `color` и `font-size` — перешли? Какие свойства наследуются по умолчанию, а какие нет?

## Задача №2 «Вложенные селекторы» (Потомки vs Дети)

— Селекторы могут выбирать элементы на разной «глубине» вложенности.

Создай HTML-страницу со списком:

```html
<ul class="menu">
    <li>Главная</li>
    <li>
        Услуги
        <ul>
            <li>Разработка</li>
            <li>Дизайн</li>
        </ul>
    </li>
    <li>Контакты</li>
</ul>
```

Напиши стили так, чтобы:

1. Всем элементам `<li>` на странице задай отступ слева.
2. **Только** элементам `<li>`, которые являются **прямыми детьми** `.menu`, задай жирный шрифт и фоновый цвет (например, светло-серый).
3. Элементам `<li>`, которые находятся **внутри** вложенного `<ul>`, задай курсив и синий цвет текста.

**Вопрос для размышления:**
Чем отличается селектор `ul li` (через пробел) от `ul > li` (через `>`)? Какой из них выберет вложенные пункты «Разработка» и «Дизайн», а какой — только «Главная», «Услуги», «Контакты»?

## Задача №3 «Таблица с полосатыми строками» (Структурные псевдоклассы)

— Таблицы данных должны читаться легко: чередование строк и подсветка при наведении помогают глазу.

Создай HTML-страницу с таблицей из 4 строк и 3 колонок (например, «Имя», «Очки», «Ранг»). У таблицы должна быть шапка (`<thead>`) и тело (`<tbody>`).

Напиши стили так, чтобы:

1. Таблица имела сплошную тонкую рамку и «схлопнутые» границы (без двойных линий).
2. Ячейки имели внутренние отступы.
3. Шапка таблицы имела тёмный фон и светлый текст.
4. **Чётные** строки в теле таблицы имели светло-серый фон (используй псевдокласс для чётных элементов).
5. При наведении на строку в теле таблицы её фон становился светло-голубым.

**Формат вывода**
Готовый HTML-код со встроенными стилями.

## Задача №4 «Группировка и порядок в каскаде» (Каскад и порядок правил)

— Если два правила имеют одинаковую «силу», побеждает то, которое написано ниже.

Создай HTML-страницу с тремя абзацами. У всех абзацев одинаковый класс `note`.
Напиши **два** правила для класса `.note`:

1. Первое правило задаёт цвет текста — красный.
2. Второе правило задаёт цвет текста — синий.

**Вопросы для размышления (ответь в комментариях):**

1. Какой цвет будет у абзацев в итоге и почему?
2. Что произойдёт, если поменять эти два правила местами?
3. Что произойдёт, если к красному цвету добавить `!important`?

**Дополнительно:** создай селектор, который задаёт отступ для нескольких разных элементов одновременно (например, для `h1`, `h2` и `p`), используя один общий блок стилей.

## Задача №5 «Псевдоэлементы и первая буква» (Псевдоэлементы `::before`, `::first-letter`)

— Иногда CSS может добавлять контент, которого нет в HTML. Это удобно для декора и типографики.

Создай HTML-страницу с заголовком `<h1>` (например, «Летопись Средиземья») и абзацем текста.

Напиши стили так, чтобы:

1. Первая буква заголовка была увеличена (например, в 2 раза больше остальных) и выделена цветом (используй псевдоэлемент для первой буквы).
2. Перед заголовком автоматически появлялся декоративный символ (например, `"✦ "`), которого нет в HTML (используй псевдоэлемент `::before` и свойство `content`).
3. После абзаца автоматически появлялась строка с текстом `"— Конец главы —"` (используй `::after`).
4. У абзаца первая строка была выделена (например, курсивом или цветом) через псевдоэлемент для первой строки.

**Формат вывода**
Готовый HTML-код со встроенными стилями.
