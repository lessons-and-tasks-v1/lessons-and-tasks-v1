## Задача №1 «Каркас летописи»

— Любая летопись начинается с основы, — сказал Элронд. — Без неё даже самая красивая история рассыплется. Собери основу так, чтобы браузер понял: это современный HTML-документ на русском языке, с корректной кодировкой и заголовком вкладки.

Создай HTML-страницу, которая:
1. Объявляет себя как документ HTML5.
2. Указывает, что язык страницы — русский.
3. Содержит служебную секцию, где заданы:
   - кодировка `UTF-8`,
   - настройка адаптивного масштабирования на мобильных,
   - заголовок вкладки браузера — `Средиземье`.
4. Содержит видимую часть с одним главным заголовком — `Добро пожаловать в Средиземье`.

**Подсказка:** подумай, какие теги отвечают за метаданные, а какие — за видимое содержимое.

**Формат вывода**
Готовый HTML-код.

## Задача №2 «Хроника похода»

— Запиши, как мы шли, — попросил Фродо. — Чтобы потомки знали. Но не просто запиши — расставь акценты.

Создай HTML-страницу, в видимой части которой:
1. Есть главный заголовок — `Поход к Ородруину`.
2. Ниже — абзац с текстом: `Путь был долгим и опасным.`
3. Под ним — горизонтальная линия, отделяющая вывод.
4. Ещё один абзац, в котором:
   - слово `важно` выглядит как логически важный текст (полужирный),
   - слово `помнить` выделено как акцент (курсив).

**Подсказка:** для акцентов есть два разных тега — один про важность, другой про интонацию.

**Формат вывода**
Готовый HTML-код.

## Задача №3 «Карта и Врата»

— Дай ссылку на карту, — сказал Гэндальф. — И покажи, как выглядят Врата. Пусть увидят и то, и другое.

Создай HTML-страницу, в видимой части которой:
1. Есть заголовок второго уровня — `Карта Средиземья`.
2. Есть ссылка на `https://lotr.fandom.com` с текстом `Карта`, которая открывается в новой вкладке.
3. Есть изображение `gates.png` (возьми любое изображение) с подписью `Врата Мории`.
4. Есть иллюстрация с подписью: изображение `moria.png` (возьми любое изображение) и под ним текст `Западные ворота Мории`.

**Подсказка:** для картинки с подписью существует специальный контейнер — не просто `<img>`.

**Формат вывода**
Готовый HTML-код.

## Задача №4 «Свиток Братства»

— Нас девять, — сказал Элронд. — Впишите имена в свиток. Но не как попало: у имён есть порядок, а у припасов — нет.

Создай HTML-страницу, в видимой части которой:
1. Есть заголовок второго уровня — `Братство Кольца`.
2. Ниже — любой список из трёх имён **по порядку**: `Фродо`, `Сэм`, `Гэндальф`.
3. Ещё ниже — заголовок третьего уровня — `Припасы`.
4. Под ним — список из трёх предметов **без порядка**: `Лембас`, `Верёвка`, `Фляга`.

**Подсказка:** подумай, чем отличается список, где важен порядок, от списка, где порядок не важен.

**Формат вывода**
Готовый HTML-код.

## Задача №5 «Донесения разведчиков»

— Собери донесения в таблицу, — приказал Арагорн. — Так виднее, кто сколько увидел.

Создай HTML-страницу, в видимой части которой:
1. Есть заголовок второго уровня — `Донесения разведчиков`.
2. Есть таблица с двумя колонками: `Имя` и `Орков`.
3. Шапка таблицы выделена отдельно от тела.
4. В теле таблицы две строки:
   - `Леголас` — `20`,
   - `Гимли` — `35`.

**Подсказка:** у таблицы есть отдельные секции для шапки и для данных — не смешивай их.

**Формат вывода**
Готовый HTML-код.
