## Цель

Освоить базовый рабочий цикл Git: клонирование репозитория, создание ветки, первый коммит и отправка изменений на удалённый сервер.

## Задания:

### № 1 Создание своей ветки
- Создать Публичный репозиторий (у себя в профиле Git).
- Клонировать репозиторий себе на комьютер
- Создать свою ветку и сразу переключиться на неё через Терминал (локально на ПК), проверить статус

### № 2 Первый коммит и отправка на сервер
- Проиндексируй изменения (git add .)
- Сделай коммит
- Отправь на удаленный репозиторий

### № 3 История и сравнение
1) Создайте файл menu.txt с двумя строками:
```bash
Главная
Контакты
```
2) Проиндексировать и сделать коммит
3) Изменить первую строку в файле menu.txt на "Главная — версия 1"
4) Используйте команду для демонстрации изменений (не git status)
5) Закоммитьте изменение (Проиндексировать и сделать коммит)
6) Посмотрите историю коммитов. Используйте флаги: сократив вывод до оной строки, ASCII-графиком ветвлений, из всех ссылок (и локальные и удаленные)

### № 4 Игнорирование файлов
1) Создайте файл .env с любым содержимым (например, SECRET_KEY=12345)
2) Создайте файл .gitignore и добавьте в него строку .env
3) Проверьте статус (Убедитесь, что .env не отображается как новый файл.)
4) Закоммитьте .gitignore (не использовать git add . - Нужно добавить только один файл)

### № 5 Ветки и слияние
1) Создайте и переключитесь на новую ветку
2) Измените файл menu.txt: добавьте третью строку "О нас".
3) Закоммитьте
4) Вернитесь в главную ветку 
5) Посмотрите на файл menu.txt — убедитесь, что третьей строки там нет (cat menu.txt)

### № 6 Слияние fast-forward
1) Создайте и переключитесь на новую ветку
2) Находясь в ветке main, выполните слияние
3) Выведите историю коммитов (показать метки веток, тегов и HEAD, все локальные ветки ).
4) убедитесь что в ветке main есть третья строка в файле (cat menu.txt)

### № 7 Трёхстороннее слияние
1) Создайте ветку  "menu-style"
2) Измените первую строку menu.txt на "Главная — стиль".
3) Закоммитьте и затем вернитесь в ветку main
4) Измените вторую строку menu.txt на Контакты — обновлено.
5) Закоммитьте и Выполните слияние. 
6) создай файл txt (в папке где изображения), ответь на два вопроса и запиши их туда 
1. Почему слияние прошло без конфликта?
2. Чем трёхстороннее слияние отличается от fast-forward?
7) Сделайте пуш в удаленный репозиторий

### № 8 Создание конфликта вручную
1) Перейдите в main
2) Создайте ветку feature/conflict-a
3) Измените первую строку menu.txt на Главная — А.
4) Закоммитьте
5) Вернитесь в main и создайте ветку feature/conflict-b
6) Измените ту же первую строку на Главная — Б. Затем Закоммитьте
7) Вернитесь в main. Слейте ветку feature/conflict-a
8) Теперь попробуйте слить feature/conflict-b

### № 9 Разрешение конфликта
1) Откройте menu.txt. Вы увидите маркеры
2) Вручную приведите файл к итоговому виду.
3) Отметьте конфликт как решённый (git add menu.txt)
4) git add menu.txt (сделайте коммит)
5) сделайте пуш в удаленный репозиторий
