## Задача 1. «Список задач с состоянием»

**Контекст.** Дан список задач. Часть помечена как выполненные (класс `done`), часть — нет. Нужно оформить его так, чтобы статус читался визуально, а HTML не менялся.

**Дано (HTML):**

```html
<ul class="todo">
  <li>Купить хлеб</li>
  <li class="done">Позвонить маме</li>
  <li>Сдать отчёт</li>
  <li class="done">Забрать посылку</li>
  <li>Полить цветы</li>
</ul>
```

**Что должно получиться:**

1. У невыполненных задач перед текстом — маркер `○`, у выполненных — `●` (символ вставляется средствами CSS, а не текстом в HTML).
2. У выполненных текст зачёркнут, а после текста стоит пометка ` ✓` (тоже вставлена CSS).
3. При наведении курсора на любую задачу её фон меняется.
4. У первой задачи сверху появляется граница, у последней — снизу.
5. Чётные задачи имеют более тёмный фон, чем нечётные.

**Ограничение:** меняем только CSS; классы и разметку не трогаем.

## Задача 2. «Хлебные крошки и меню навигации»

**Контекст.** На странице есть навигационная цепочка («хлебные крошки») и горизонтальное меню. Нужно оформить их так, чтобы разделители, активный пункт и состояния ссылок были видны — без добавления лишних элементов в HTML.

**Дано (HTML):**

```html
<nav class="breadcrumbs">
  <a href="/">Главная</a>
  <a href="/catalog">Каталог</a>
  <a href="/catalog/books">Книги</a>
  <span>Фантастика</span>
</nav>

<ul class="menu">
  <li><a href="/">Главная</a></li>
  <li><a href="/about">О нас</a></li>
  <li><a href="/contacts" class="active">Контакты</a></li>
  <li><a href="/blog">Блог</a></li>
</ul>
```

**Что должно получиться:**

1. Между элементами хлебных крошек (кроме последнего) появляется разделитель `/` — вставляется CSS, не текстом.
2. Последний элемент крошек (это `span`, не ссылка) — не кликабельный, серый, без подчёркивания.
3. При наведении на ссылку в крошках меняется цвет.
4. В меню у активного пункта (`.active`) — подчёркивание и жирный шрифт.
5. При наведении на пункт меню — подсветка фона.
6. У первого пункта меню слева появляется вертикальная полоса-акцент (вставляется CSS).

**Ограничение:** только CSS; HTML не меняем. Подумайте, как отличить «последний элемент» и «элемент, который не ссылка».

## Задача 3. «Карточки товаров с бейджами и счётчиком»

**Контекст.** Витрина товаров. У части карточек в атрибуте `data-badge` указан тип бейджа. Нужно оформить витрину через CSS: бейджи, нумерация, реакция на курсор, выделение каждой третьей, пунктир у карточек без бейджа и итоговый счётчик.

**Дано (HTML):**

```html
<div class="grid">
  <div class="card" data-badge="new">Товар 1</div>
  <div class="card" data-badge="sale">Товар 2</div>
  <div class="card">Товар 3</div>
  <div class="card" data-badge="new">Товар 4</div>
  <div class="card">Товар 5</div>
  <div class="card" data-badge="sale">Товар 6</div>
</div>
```

**Что должно получиться:**

1. У карточек с бейджем `new` в углу появляется зелёная плашка `NEW`, у карточек с бейджем `sale` — красная плашка `SALE`. Текст плашек вставляется CSS.
2. У каждой карточки в углу — её порядковый номер (1, 2, 3, …), вставляется CSS-счётчиком.
3. При наведении курсора на карточку она приподнимается на 4px и получает тень; переход плавный.
4. Каждая третья карточка имеет другой фон.
5. Карточки **без** бейджа обведены пунктирной рамкой.
6. Внизу сетки выводится строка «Всего: 6» — тоже средствами CSS-счётчика.
