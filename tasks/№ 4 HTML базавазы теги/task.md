## Задача №6 «Знамя отряда»

— Каждый отряд должен иметь своё знамя, — сказал Боромир. — Но знамя — это не просто строка текста. Подумай, чем сгруппировать девиз и текст, чтобы они держались вместе.

Создай HTML-страницу, в видимой части которой:

1. Есть главный заголовок — `Знамя отряда`.
2. Ниже — блок, внутри которого:
   - заголовок второго уровня — `Девиз`,
   - абзац с текстом `Мы идём до конца.`.
3. Под блоком — ещё один блок с текстом `Отряд готов к походу.`.

**Подсказка:** для группировки содержимого в блоки есть универсальный блочный контейнер. Он начинает новую строку и может содержать другие элементы.

**Формат вывода**
Готовый HTML-код.

## Задача №7 «Метка на клинке»

— На клинке должна быть метка, — сказал Арагорн. — Но не целая строка, а только одно слово. Строку разрывать нельзя.

Создай HTML-страницу, в видимой части которой:

1. Есть заголовок второго уровня — `Клинок`.
2. Ниже — абзац с текстом: `Этот клинок выкован в ` — затем слово `Гондоре`, обёрнутое в контейнер, — затем продолжение: ` и не знает поражений.`.
3. Под абзацем — ещё один абзац: `Сталь ` + слово `эльфийская` в контейнере + ` сверкает на солнце.`.

**Подсказка:** нужен контейнер, который не разрывает строку и выделяет часть текста внутри неё. Блочный контейнер здесь не подойдёт.

**Формат вывода**
Готовый HTML-код.

## Задача №8 «Свиток с печатями»

— Раздели свиток на части, — попросил Гэндальф. — Пусть каждая часть будет в своей рамке-контейнере.

Создай HTML-страницу, в видимой части которой:

1. Есть заголовок второго уровня — `Свиток Братства`.
2. Ниже — три блока подряд:
   - в первом — абзац `Первая печать: Фродо.`,
   - во втором — абзац `Вторая печать: Сэм.`,
   - в третьем — абзац `Третья печать: Гэндальф.`.
3. Внутри второго блока слово `Сэм` обёрнуто в строчный контейнер.

**Подсказка:** блочные контейнеры можно ставить рядом — каждый займёт свою строку. А внутри блока для одного слова понадобится строчный контейнер.

**Формат вывода**
Готовый HTML-код.

## Задача №9 «Надпись на камне»

— Высеки надпись, — сказал Гимли. — Но выдели в ней главное слово, чтобы его заметили.

Создай HTML-страницу, в видимой части которой:

1. Есть заголовок второго уровня — `Надпись на камне`.
2. Ниже — блок, внутри которого абзац:
   - текст `Здесь покоится ` ,
   - слово `Балин`, обёрнутое в строчный контейнер,
   - текст `, сын Фундина.`.
3. Под блоком — горизонтальная линия.
4. Ниже линии — абзац, в котором слово `помни` выделено курсивом, а слово `смелость` — полужирным.

**Подсказка:** сначала подумай, чем сгруппировать надпись, а внутри для одного слова возьми контейнер, который не разрывает строку. Для акцентов есть два разных тега — один про важность, другой про интонацию.

**Формат вывода**
Готовый HTML-код.

## Задача №10 «Привал в Лориэне»

— Опиши привал, — сказала Галадриэль. — И покажи, что у нас есть и место для отдыха, и место для припасов. Пусть каждая часть держится отдельно.

Создай HTML-страницу, в видимой части которой:

1. Есть главный заголовок — `Привал в Лориэне`.
2. Ниже — первый блок, внутри которого:
   - заголовок третьего уровня — `Место отдыха`,
   - абзац `Под кронами маллорнов.`.
3. Под ним — второй блок, внутри которого:
   - заголовок третьего уровня — `Припасы`,
   - список без порядка из трёх предметов: `Лембас`, `Верёвка`, `Фляга`.
4. В абзаце первого блока слово `маллорнов` обёрнуто в строчный контейнер.

**Подсказка:** блок-контейнер может содержать и заголовки, и списки — всё, что нужно сгруппировать вместе. А для одного слова внутри абзаца хватит строчного контейнера.

**Формат вывода**
Готовый HTML-код.
